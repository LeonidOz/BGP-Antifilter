# Установка через Portainer

[Быстрая установка через терминал](../README.md) | [English](portainer.en.md)

Нужен Docker Standalone на Linux. В примере MikroTik имеет адрес `192.168.55.1`,
а Linux-сервер — `192.168.55.5`. Замените их на свои.

## 1. Создайте стек

В Portainer откройте **Stacks → Add stack**, задайте имя `bgp-antifilter`
и выберите **Web editor**. Вставьте содержимое
[готового файла стека](../deploy/portainer-stack.yml).
Клонировать репозиторий и собирать образ не нужно.

## 2. Задайте переменные

Добавьте значения в **Environment variables**:

| Переменная | Пример | Назначение |
| --- | --- | --- |
| `BGP_ANTIFILTER_IMAGE` | `ghcr.io/leonidoz/bgp-antifilter:0.5.2` | Готовый образ приложения |
| `ADMIN_PASSWORD` | Ваш пароль | Вход в веб-панель |
| `MT_IP` | `192.168.55.1` | Адрес MikroTik |
| `BIRD_IP` | `192.168.55.5` | Существующий адрес Linux-сервера |
| `ROUTER_ID` | `192.168.55.5` | Обычно совпадает с `BIRD_IP` |
| `MY_AS` | `64500` | AS приложения |
| `MT_AS` | `65455` | AS MikroTik |
| `BGP_COMMUNITY` | `65432,500` | Метка маршрутов для фильтра MikroTik |

Для другого порта панели добавьте `ADMIN_PORT`, например `8081`.
Порты панели и BGP (TCP 179) должны быть свободны на Linux-сервере.
Сетевой режим хоста уже указан в стеке; отдельно публиковать порты не нужно.

## 3. Запустите и подключите роутер

Нажмите **Deploy the stack** и дождитесь первой загрузки маршрутов.
Откройте **http://192.168.55.5:8080** и введите заданный пароль.
Затем выполните [настройку MikroTik](mikrotik.md).

До подключения MikroTik контейнер может показывать `unhealthy`, поскольку проверяет
наличие BGP-соединения. После настройки ожидаются маршруты в панели и состояние BGP `Established`.

## Обновление и данные

Для обновления измените тег в `BGP_ANTIFILTER_IMAGE` и нажмите **Update the stack**
с повторным скачиванием образа. В этом способе установки приложение обновляется через Portainer.

В новой схеме списки, настройки и их резервные копии хранятся в томе `bgp-antifilter-config`,
а маршруты, кеш и runtime — в прежнем томе `bgp-antifilter-data`.
Сохраняйте оба тома при обновлении и пересоздании стека.
Для подключения существующего тома задайте `BGP_DATA_VOLUME=<имя-тома>`
и `BGP_DATA_EXTERNAL=true`. Данные из прежней папки `generated/`
нужно перенести в том отдельно: автоматически они не появятся.
Для существующего тома конфигурации задайте `BGP_CONFIG_VOLUME=<имя-тома>`
и `BGP_CONFIG_EXTERNAL=true`; иначе новый том будет создан автоматически.

При переходе со старого стека обновите и образ, и содержимое YAML до схемы с двумя томами.
Автоматическая миграция доступна начиная с [0.5.2](../CHANGELOG.md#052---2026-11-13); образ `0.5.1` её ещё не содержит.
Первый запуск скопирует конфигурацию из старого тома, сохранив оригиналы и маршруты.
Обновление только образа со старым YAML продолжает использовать явно заданные старые пути.
Перед переходом сделайте резервную копию; см. [порядок миграции](usage.md#переход-к-раздельному-хранению).
